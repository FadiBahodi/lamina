Public documentation cannot reveal every vendor's internal cache, source policy or review process. Claims of speed and quality from any vendor, including Lamina, need the same task-level test.

## Lamina's current scope

The source-aware production path records selected text sources, roles, locators, extracted ideas, routes, sections, review findings and revisions. Optional retrieval targets give extracted ideas one owner and preserve source-backed answer items in guides or examiner material. Assessment runs separate candidate-only solve calls from key-and-evidence judgments. A configured local adapter can render PCM WAV and record hashes and duration. The generic [method runtime](methods.md) runs a separate declared graph with resource lanes, cached nodes, receipts and manually selected observations.

These mechanisms cover parts of five practical questions: which text was selected, how it was grouped, where assigned material landed, what was re-executed after revision, and which local artifact was saved. They do not inventory every visual source region, infer all semantic dependencies, guarantee that a model merged concepts correctly, administer a live case, verify speech by listening or ASR, or select and improve methods automatically. [Architecture status](architecture-status.md) gives the current boundary.

The useful competitive hypothesis is specific: for a defined source set and output, a human can locate and repair a missed or misgrouped item with less total work while reaching comparable judged quality. Lamina may lose on first-draft speed, media polish, tool access or setup time. A quality-matched test would determine whether the repair benefit matters enough to the intended users.

## Fair comparison

Give each system the same lawful sources, brief, deadline, source-role rules, deliverables and access to its documented features. Use a capable operator and count manual supervision. Compare complete journeys through accepted delivery, including revision after a source change. A LangGraph comparison needs a built application, rather than a library import.

Blind artifact reviewers to product where practical. Measure source coverage and output quality separately, then record total cost, elapsed time, retries, human review and delivery. Use a new corpus and a fresh operator or agent to test transfer. If a task was tailored to Lamina's schema, report that limit. The [measurement protocol](measurement.md) specifies the run design.
