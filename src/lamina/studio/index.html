A WORKER'S VIEW

Small source packet, clear ownership

Each reading task sees one passage and a short stretch of its neighbors. The worker must quote its own passage for any proposed idea. That keeps source links checkable, but adjacent text alone cannot tell a writer how the entire finished guide should connect.

A DEPENDENCY & RECOVERY

Parallel where possible; pause at shared decisions

Source passages can be read in parallel. Joining related ideas and planning lessons are currently whole-collection steps. Lessons then run in parallel. Results are cached by their inputs and procedure revision; a failed review blocks export, while completed steps can be reused on retry. A cache entry records a prior response, not its quality.

RESOURCE REALITY

Speed requires a real workload

The published benchmark measures local queue and cache mechanics with timed placeholders. It does not measure model calls, audio generation, teaching quality, or total time to a usable result. Larger collections still hit global context limits; model input, retries, review, and memory use must be measured on real jobs.
