How it works

Divide the work.
Share the context.

Readers work in parallel from original passages and nearby context. A planner organizes their findings. Writers receive the evidence and shared context for each section, then completed sections move into review.

Use a built-in workflow or define your own jobs and dependencies. Models make the editorial decisions; Lamina handles scheduling, source references, caching and recovery.

Get started

Connect a model.
Run it locally.

Generation requires an LLM connection and its credentials. Configure an adapter in models.json, then open http://127.0.0.1:8048. You can also use the CLI or Python API.

Configure your model ↗
Terminal
git clone https://github.com/FadiBahodi/lamina.git
cd lamina
python -m venv .venv
source .venv/bin/activate
pip install '.[pdf,slides,http,tokens]'

# After configuring models.json:
lamina app --adapter @models.json

Windows: activate with .venv\Scripts\activate.

Current limits

Generated work needs review, including figures and spoken delivery. Lamina runs configured workflows; discovering and learning better workflows remains research. Exported cases do not include a live oral-exam interface. See capability status.
