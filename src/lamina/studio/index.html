ARCHITECTURE / EXECUTED & PROPOSED

A production pipeline with a research frontier.

The current engine builds traceable artifacts. Reusable learning methods and persistent memory are directions for evaluation, not deployed capabilities.

EXECUTED PIPELINE
Source units → extracted ideas → semantic merge → curriculum → authored output → review
01 / INPUT

Address source units

Filename, heading, locator, and original passage stay available. PDF text extraction is limited by figures and layout.

02 / SEMANTICS

Ground concepts

Exact quotes are validated against source units. They establish provenance, while interpretation still needs evaluation.

03 / CURRICULUM

Assign or defer

Extracted concepts enter a lesson plan or an explicit deferral. Coverage describes assigned extraction, not complete understanding.

04 / DELIVERY

Publish forms

Study guide, progressive assessment, oral scenario, and audio script share a base lesson bundle.

PROPOSED / NOT CURRENT RUNTIME

Reusable methods + learner memory

A future layer could compare procedures across collections, track learner evidence over time, and adapt sequencing. This release does not persist a learner model or demonstrate transfer. The published build supports inspecting the transformations and evaluating where that layer would connect.
